◆ Langsys × TypeScript

t() — inline string, wired to the DOM

t('Hello, {name}!', 'Greetings', { name })

Hello, Sarah!

t() — plurals, written flat

t(
  'Hello, {name}! You have {count} new messages.',
  'Greetings',
  { name, count },
)

Hello, Sarah! You have 3 new messages.

3

Change count to 1 and back — the grammar follows. Every locale applies its own plural rules.

Translate — content block

// <section id="hero"><h3>Welcome to our store</h3>…</section>
new Translate(hero, { category: 'Home' })

Welcome to our store

Browse the catalog in your language.

Phrase — params & markup

// <p id="cart-note">Hi {name}, you have {count} items in your cart.</p>
new Phrase(cartNote, { category: 'Cart', params: { name, count } })

Hi {name}, you have {count} items in your cart.

3

t() — dates and numbers, per locale

t('Your order {id} ships on {date}.', 'Checkout', {
  id: '48213',
  date: new Date(2026, 7, 15),
})

Your order 48213 ships on Aug 15, 2026.

The date is formatted for each locale; the order id is a string, so it stays as written.

translate="no" — never translated

<p id="signin">
  Welcome!
  <span translate="no">
    This sentence always stays in English.
  </span>
  Thanks for visiting!
</p>

Welcome! This sentence always stays in English. Thanks for visiting!

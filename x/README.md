# X account assets

Branding for the official Langsys account on X. It follows the [YouTube channel kit](../youtube) so both profiles look the same.

| File | Size | Use |
| --- | --- | --- |
| `avatar.png` | 800×800 | Profile picture. The same file as `../youtube/avatar.png`: black hexagon on white, padded so X's circular crop doesn't clip the hexagon's points. X recommends 400×400 and scales the larger file down. |
| `header.png` | 1500×500 | Header. The YouTube banner's tagline and "Hello" in seven languages, laid out for X's 3:1 header. All the text sits between y≈130 and y≈325, so the profile picture, which covers the bottom-left corner, never sits on top of it, and the slight top/bottom crop on phones leaves it intact. No logo or wordmark: the profile picture and name sit right below. White background in the logo's colours: near-black `#231F20`, greys `#6D6E71` / `#8A8C8F` / `#A7A9AC`. |
